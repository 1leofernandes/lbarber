### Sistema Completo para Barbearia

**páginas:**

> login
> register
> cliente-home
> agendamento
> admin
> barbeiro

**Conta com diversas funções, como:**
_Google OAuth, Mercado Pago API (pagamentos e assinaturas recorrentes), Agenda completa, Gestão de barbeiros e serviços, Planos de assinaturas, Dashboard financeiro e etc..._

## Tecnologias:

HTML, CSS, JS, NODE.JS, JWT, EXPRESS.JS, OAUTH, POSTGRESQL, REDIS CACHE, BCRYPTJS, FASTIFY
